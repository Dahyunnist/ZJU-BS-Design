# k6 本地检索样本

日期：2026-10-21

## 方法

- k6 `0.57.0` 在本机 Docker Compose 网络内运行；登录使用临时专用账号，不向容器传入预先生成的 JWT。
- 为临时账号创建 10,000 行 `READY` 图片元数据，所有账号和图片数据在测试后级联删除；测试后数据库临时账号数和 fixture 行数均为 0。
- offset 与 cursor 列表各以 10、50、100 VU 运行 15 秒；缓存关闭/开启比较采用空结果搜索、50 VU、15 秒。每组单次，无预热。
- offset/cursor 测试使用默认 Redis 缓存开启配置；缓存对照通过 `APP_CACHE_ENABLED=true/false` 重启 API，使用 `NoOpCacheManager` 关闭缓存。
- 硬件与数据库：Intel Core i9-13980HX，24 核 / 32 逻辑处理器；Docker VM 内存 7.566 GiB；MySQL 8.0.46。k6 与应用共用 Docker VM 资源。
- 阈值：HTTP 失败率低于 1%，p95 低于 1 秒。
